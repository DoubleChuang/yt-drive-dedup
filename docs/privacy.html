隱私權政策

Privacy Policy · 最後更新：2026 年 11 月 8 日

本隱私權政策說明 DeleteDuplicateVideo（以下稱「本應用程式」）如何存取、使用、儲存與保護 Google 使用者資料。本應用程式為個人自用工具，僅供其擁有者（以下稱「使用者」）本人的 Google 帳號使用，不對外提供服務，也沒有其他使用者。

1. 取得的資料與用途

本應用程式僅在使用者本人授權後，存取下列資料，且用途嚴格限於該功能：

Google 服務權限存取內容用途
Google Drive drive 使用者自己 Drive 中的影片檔案及其中繼資料（檔名、大小、影片長度） 比對是否與 YouTube 已上傳影片重複；經使用者確認後將重複檔移至垃圾桶
YouTube youtube.readonly 使用者自己頻道的已上傳影片清單、標題與長度 作為重複比對的依據
Gmail gmail.readonly、gmail.modify、gmail.send 使用者信箱中的信件標題、寄件者、內文摘要 產生每日重要信件摘要、貼上分類標籤；寄送功能僅用於使用者本人指定的通知
Google Calendar calendar 使用者自己的行程 彙整每日摘要

2. 資料的儲存與保留

  • 所有資料僅儲存在使用者自己的電腦上（本機檔案與本機瀏覽器授權憑證）。
  • 本應用程式沒有任何遠端伺服器、雲端資料庫或分析服務。
  • 授權憑證（OAuth token）保存在使用者電腦的 ~/.hermes/google_token.json，可隨時刪除。
  • 使用者可隨時撤銷授權：Google 帳號權限頁面。

3. 資料的分享

本應用程式不會將 Google 使用者資料出售、出租、轉讓或提供給任何第三方， 也不會用於廣告、行銷、信用評估或任何與上述用途無關的目的。 資料不會被人工閱讀，除非使用者自己為了除錯而查看本機輸出。

4. 資料傳輸

本應用程式直接在使用者電腦與 Google API 之間傳輸資料（HTTPS）。 除了 Google 官方 API 之外，不會把資料傳送到任何其他端點。

5. Google API Services User Data Policy 遵循聲明

本應用程式對 Google API 所取得資訊的使用，遵守 Google API Services User Data Policy， 包含 Limited Use（限制使用）要求：

  • 僅為提供本應用程式所述功能而使用資料。
  • 不將資料轉移給第三方，除非為提供功能所必要、為遵守法律，或經使用者明確同意。
  • 不用於廣告目的。
  • 不允許人類閱讀這些資料，除非使用者主動檢視自己的本機輸出、為安全目的（如濫用調查）或為遵守法律。

6. 兒童隱私

本應用程式為個人工具，非供兒童使用，也不會刻意蒐集兒童資料。
